## Isi body issue yang disarankan

Gunakan format berikut pada setiap issue:

```markdown
## Tujuan
Jelaskan hasil yang ingin dicapai oleh issue ini.

## Task
- [ ] Langkah implementasi pertama
- [ ] Langkah implementasi kedua
- [ ] Review dan pengujian

## Acceptance Criteria
- [ ] Deliverable dapat diperiksa oleh anggota lain
- [ ] Perubahan telah melalui pull request/review
- [ ] Dokumentasi terkait telah diperbarui
```

## Pengaturan GitHub Project

1. Buat project baru bernama **MeetPlan Development** dengan tampilan Board.
2. Buat kolom/status **Todo**, **In Progress**, dan **Done**.
3. Buat 18 issue di atas pada repository `arimbiarumsari/MeetPlan`.
4. Tambahkan setiap issue ke project, lalu isi assignee, label, dan sprint/milestone.
5. Untuk screenshot awal, tampilkan seluruh issue pada kolom **Todo**.
6. Setelah satu minggu, pindahkan issue sesuai kondisi nyata; jangan merekayasa status pekerjaan.

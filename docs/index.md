# MeetPlan

## About MeetPlan

MeetPlan adalah platform perencanaan acara yang membantu kelompok menentukan waktu, tempat, dan aktivitas bersama secara lebih mudah.

## Problem

Perencanaan acara kelompok sering membutuhkan banyak percakapan untuk menentukan waktu yang cocok, memilih tempat atau aktivitas, dan memastikan semua anggota merasa nyaman.

## Solution

MeetPlan mengintegrasikan:

- Availability Calendar
- Tidak Bisa Di-cancel
- Tentatif
- Automatic Time Search
- Place & Activity Polling
- Anonymous "Pengen Cancel"
- Event Summary
